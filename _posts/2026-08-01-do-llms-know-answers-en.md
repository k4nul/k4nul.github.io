## Summary / 요약

An LLM response is not, by itself, evidence that the model looked up a fact. In the standard generative framing, a model produces a continuation conditioned on the input and prior generated tokens. That is different from returning a stored database record or retrieving a document. The distinction helps a team use generation for drafting and explanation while preserving a separate source of truth for current facts.

## Problem Statement / 문제 정의

Saying that an AI “knows” an answer combines several systems that fail in different ways. A customer-order question may require an operational database; a policy question may require a dated source document; a request to rewrite a policy may require language generation. Calling all three “AI knowledge” obscures where to inspect an error and can make generated prose appear more authoritative than its evidence supports.

## Verified Facts / 확인된 사실

The Transformer paper introduced an architecture based on attention rather than recurrence or convolution [Vaswani et al.](https://arxiv.org/abs/1706.03762). The OpenAI prompt guide describes a context window as the bounded data a model can consider for a generation request and describes retrieval-augmented generation as adding retrieved context to that request ([official guide](https://developers.openai.com/api/docs/guides/prompt-engineering)). RAG research likewise describes combining a parametric generator with a non-parametric document index ([Lewis et al.](https://arxiv.org/abs/2005.11401)). These sources do not establish that a fluent sentence proves a current external fact.

## Reproduction Steps / 재현 순서

No benchmark is reproduced here. Instead, classify a question before choosing a system: use a source-of-record query for “What is the current order status?”, retrieve and cite dated documents for “What does the current policy say?”, and use an LLM with supplied material for “Turn this policy into a customer explanation.” Then compare the final claim with the returned record or cited text, not merely with the wording of the generation.

## Observations / 관찰 결과

This classification makes investigation actionable. A wrong database answer points to stored values, synchronization, or query conditions. A wrong retrieval answer points to document freshness, indexing, ranking, and access filters. A wrong generated answer points to the supplied context, instructions, output constraints, and validation. A URL-shaped string generated by a model is not a citation unless it is connected to an actually retrieved or supplied source.

## Interpretation / 해석

My interpretation is that “contextual language generator” is a safer working model than “answer store.” It does not diminish useful capabilities: generation can summarize verified material, compare supplied documents, and prepare a reviewable draft. It does mean that high-consequence claims should keep their evidence in a system that can identify the original record, document version, and time of retrieval.

## Limitations / 한계

This article does not inspect a particular model’s internal representation or compare products. Retrieval does not automatically make an answer correct, authorized, or faithfully cited. Domain-specific controls remain necessary for medical, legal, financial, or other high-impact decisions. This is a design interpretation, not a direct experiment.
